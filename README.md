# llms.txt — Kane Mayfield

Machine-readable index for [kanemayfield.com](https://kanemayfield.com), built on the [llms.txt specification](https://llmstxt.org/).

## What This Is

A routing index and linked sub-documents designed to give LLMs structured, accurate context about Kane Mayfield's work across music, literature, software development, visual art, physical product design, blockchain, comedy, and community education.

The main `llms.txt` file serves as a table of contents. Each sub-document in `/llms/` covers one discipline in depth and cross-references the others — pull any single thread and you get signal from every direction.
